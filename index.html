Инструкция

Как добавить музыку

Способ 1: Нажмите «Добавить треки» → выберите файлы.

Способ 2: Перетащите MP3/MP4 файлы в окно.

Управление

В строке плеера: ⏮ предыдущий · ▶ играть/пауза · ⏭ следующий · 🔀 перемешать · 🔁 повтор.

Слайдеры громкости и скорости — под кнопками плеера.

Плейлисты

Создать: кнопка «+» в строке плейлистов.

Переименовать: кнопка с карандашом (нельзя для Default).

Удалить: кнопка с корзиной — удаляет плейлист и все его треки (нельзя для Default).

Переключиться: выпадающий список слева.

Экспорт/импорт: кнопки со стрелками рядом — сохраняют и восстанавливают плейлист вместе с аудиоданными.

Очистка: «Очистить плейлист» удаляет треки только из выбранного плейлиста. Другие плейлисты не трогаются.

Добавление: новые треки попадают в текущий выбранный плейлист.

Хранилище

Телефон: до 10 ГБ. Компьютер: до 500 ГБ.

Музыка хранится локально в IndexedDB — данные на сервер не уходят.

Офлайн режим

1. Один раз откройте приложение онлайн (для регистрации Service Worker).

2. Дальше слушайте без интернета.

Форматы

MP3, WAV, OGG, FLAC, M4A, AAC. MP4/M4V — только звук.

Горячие клавиши

Пробел — Играть/Пауза

← / → — Предыдущий / следующий трек

Shift + ← / → — Перемотка ±10 сек

↑ / ↓ — Громкость

M — Без звука

S — Перемешать

R — Повтор

Настройки приложения

Откройте шестерёнку в шапке: цветовые акценты, таймер сна, визуализатор, текст песни, Chromecast.

Установить как приложение

iPhone: Safari → Поделиться → На экран «Домой».

Android: Chrome → Меню → Установить приложение.

Desktop: Chrome/Edge → значок установки в адресной строке.
